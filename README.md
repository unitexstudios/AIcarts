# EZBOT — 시각장애인 보행보조 로봇

제22회 임베디드 소프트웨어 경진대회 자유공모 부문 출품작 (팀명 EZ, 3인 팀) · 장려상

국가철도의 점자 편의시설 설치율이 낮다는 문제에서 출발해, 시각장애인을 기차역 승강장 탑승 위치까지 안내하는 보행보조 로봇을 제작했습니다. 본선 전시에서 시연 가능한 수준까지 실물을 완성했고, 한국재활복지공학회(RESKO) 학술대회 포스터로도 발표했습니다.

설계 도면과 사진, 개발완료보고서는 포트폴리오 페이지에 정리해 두었습니다.
→ https://unitexstudios.github.io/projects/ezbot.html

## 이 저장소의 범위

`ezbot.py`는 Raspberry Pi에서 동작하는 로봇 제어 소프트웨어입니다.

**이 코드는 3인 팀의 공동 작업물이며, 주행 제어 소프트웨어와 QR 인식, 다국어 음성 안내는 팀원이 작성했습니다.** 저장소 소유자(이경진)가 담당한 부분은 기구 설계와 3D 프린팅 제작, 전장 배선과 결선도 작성, 장비 상태 확인·수동 조작용 테스트 앱입니다.

## 동작 순서

PIR 센서로 이용자 감지 → 승차권 QR 스캔으로 목적지·언어 확인 → 음성 안내 → 승강장까지 주행 → 무선으로 엘리베이터 호출 → 도착 후 자동 복귀

## 구성

| 기능 | 구현 |
|---|---|
| 이용자 감지 | PIR 센서 |
| 목적지 인식 | OpenCV + pyzbar QR 디코딩, NFC(ACR122U) 게이트 태그 |
| 장애물·혼잡 인식 | YOLOv5 (torch hub) |
| 추락·높이 감지 | 초음파 센서 |
| 주행 | RPi.GPIO PWM 모터 제어 |
| 엘리베이터 호출 | Bluetooth RFCOMM |
| 음성 안내 | gTTS (한국어·영어·중국어) |
| 안전 | 손잡이 이탈 시 동력 차단, 비상정지 입력 |

## 알려진 한계

주행은 `time.sleep()` 기반 개루프 제어입니다. 엔코더나 라인 추종 같은 폐루프 피드백이 없어 바닥 상태와 배터리 전압에 따라 실제 이동 거리가 달라지며, 본선 전시에서는 현장 환경에 맞춰 시간값을 보정해 운용했습니다.

## 실행 환경

Raspberry Pi · Python 3

```
RPi.GPIO  opencv-python  pyzbar  torch (YOLOv5)  pybluez  nfcpy  pyscard  gTTS  pygame  numpy
```
